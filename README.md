# Curso de Python

Este repositorio contiene una colección de lecciones, ejercicios y proyectos prácticos diseñados para aprender y practicar Python. A continuación, se detalla la estructura del proyecto y los temas cubiertos.

## Estructura del Proyecto

### Lecciones

1. **Lesson1**: Introducción a Python
   - Uso de variables
   - Tipos de datos
   - Entrada y salida de datos
   - Ejercicios básicos como "Hola Mundo" y operaciones matemáticas.

2. **Lesson2**: Operadores en Python
   - Operadores aritméticos, de comparación y lógicos.
   - Ejercicios prácticos como determinar el mayor de dos números y trabajar con rangos.

3. **Lesson3**: Condicionales
   - Uso de estructuras condicionales como `if`, `elif`, y `else`.
   - Ejercicios como determinar la estación del año o la etapa de vida según la edad.

4. **Lesson4**: Ciclos
   - Uso de ciclos `for` y `while`.
   - Ejercicios como contar en decrementos y usar `break` y `continue`.

5. **Lesson5**: Estructuras de datos
   - Listas, tuplas, conjuntos y diccionarios.
   - Ejercicios prácticos como trabajar con rangos divisibles por 3 y manipulación de datos.

### Proyectos Prácticos

- **Sistema de Encriptación**: Una aplicación para encriptar y desencriptar mensajes e imágenes.
  - Incluye interfaces gráficas creadas con PyQt5.
  - Archivos de ejemplo para probar la funcionalidad.

- **Convertir Audio a Texto**: Un script para transcribir audio a texto.

- **Calculadora**: Una calculadora básica implementada en Python.

### Ejercicios Adicionales

- Ejercicios variados como trabajar con signos zodiacales, tablas de multiplicar, y más.

## Requisitos

- Python 3.8 o superior.
- Bibliotecas adicionales como PyQt5 (para el sistema de encriptación).

## Cómo Usar Este Repositorio

1. Clona el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Navega a la carpeta correspondiente a la lección o proyecto que deseas explorar.
3. Ejecuta los scripts con Python:
   ```bash
   python <nombre_del_script>.py
   ```
